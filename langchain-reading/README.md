## 六项跃升标准

1. **30min 出地图** — 陌生 repo，README → pyproject → `__init__.py`
2. **15min 定位扩展点** — 新 LLM / 存储 / 中间件，最少改哪几个类
3. **1h 跟完主链路** — 公开 API → 返回，迷路 ≤3，有形变表
4. **读设计** — `@deprecated`、包拆分、Middleware 能说出**为什么**
5. **读法切换** — LangChain 外→内；imooc-llmops 入口→主链路
6. **二手资料降级** — 先预测再读码，5 次命中率 ≥60%

详见：[`00-六项跃升标准.md`](00-六项跃升标准.md)

## 每日流程（约 3 小时 · Task1→2→3）

| Task | 主旨 | 子项 |
|------|------|------|
| **Task 1 · 读** | 输入 | 1.1 读什么 / 1.2 为何要读 |
| **Task 2 · 练** | 动手 | 2.1 练什么 / 2.2 为何要练 |
| **Task 3 · 整理** | 输出 | 3.1 交付物（Task1/2 成果）/ 3.2 读码日志（**必写**） |

> Task2 的结果应能直接写入 Task3 交付物；验收日在 Task2，Task3 记录计时与通过与否。

**硬规则**：验收未通过 → 延长该周，不进入下一阶段。
