## 每次「新的一天」怎么开始（复制发给 AI）

将下面整段复制到新对话第一条消息（按需改 `[日期]`）：

```
@langchain/langchain-reading/源码阅读训练.md @langchain/langchain-reading/00-当前进度与续接.md

我在进行 LangChain 源码阅读训练（v2.1，Task1/2/3 + QPSVCR + 逐日能力训练矩阵）。
请严格以「00-当前进度与续接.md」为进度源，以「源码阅读训练.md」为步骤源。

1. 读取当前进度，确认我上次停在哪一步
2. 若上一步标注「待确认」，先验收我的理解再继续
3. 带我完成「下一动作」的 Task1→Task2→Task3，并执行当天矩阵中的阅读动作、限制条件和误判复盘（每天约 3 小时）
4. 结束时：**审核交付物** → 更新 `00-当前进度与续接.md` → 更新当日读码日志

今天日期：[日期]。我开始继续训练。
```

**更短版（熟练后）：**

```
@langchain/langchain-reading/00-当前进度与续接.md 续接训练，按逐日能力训练矩阵完成下一步 Task1→2→3 并更新进度文件。
```

## 每次会话结束 checklist（你或 AI 必做）

**顺序**：交付物交审核 → 通过则更新续接 → 更新日志

1. [ ] **审核** — 学员聊天 @ 读码日志 + 交付物；AI 审核，通过则日志改「通过」并定稿
2. [ ] `00-当前进度与续接.md` — 步骤状态、下一动作、**下一文件**（以 `源码阅读训练.md` 为准）
3. [ ] `09-读码日志/` — 学员写 Task2 答案 +「待审」；**审核通过** AI 改为「通过」
4. [ ] `00-六项跃升标准.md` — 若当天有闭卷验收，记录计时与通过与否
5. [ ] `README.md` 进度勾选 — 阶段完成时更新

> **不在读码日志里写「明天打开哪个文件」** — 续接文件的「下一文件」+ 训练规划 Day 块即唯一来源。

## AI 必须遵守的规则（写入本协议）

1. **不跳步**：未通过上一步确认 / 验收，不进入下一步。
2. **不擅自改规划**：以 `源码阅读训练.md` v2.1 为准；若需调整，先说明理由并更新本文件。
3. **天数只是标签**：不说「你落后了」；只说「步骤 N 未完成 / 验收未过」。
4. **闭卷验收日**：我只出题与规则；**计时闭卷由你独立完成**，再向我汇报结果。
5. **结束必写续接**：每轮对话最后更新本文件「当前状态」表。
