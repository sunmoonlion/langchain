## §1 它是什么（3 句话）

1. LangChain 是一个用于构建 **Agent 与 LLM 应用** 的 Python 框架，提供可互操作的组件与第三方集成，把模型、工具、数据串起来。
2. 在官方生态里，它定位为 **「agent engineering platform」** 的核心层：不是最底层的编排引擎（那是 LangGraph），也不是开箱即用的高级 Agent（那是 Deep Agents），而是 **可组装的 Agent harness**（`create_agent` = model + tools + prompt + middleware）。
3. 它 **可以独立使用**，也可与 LangGraph（编排/runtime）、LangSmith（trace/eval/deploy）、Integrations（各厂商适配包）组合成完整工程栈。

## §7 生态关系图（初稿 · Day 1）

```
                    ┌─────────────────┐
                    │   Deep Agents   │   batteries-included（规划/子Agent/文件系统）
                    └────────┬────────┘
                             │  built on
                    ┌────────▼────────┐
                    │    LangChain    │  create_agent harness（model+tools+prompt+middleware）
                    │  init_chat_model│  更低门槛：先连上模型
                    └────────┬────────┘
                             │  agents built on
                    ┌────────▼────────┐
                    │    LangGraph    │  底层编排：状态图、持久化、HITL、durable execution
                    └────────┬────────┘
                             │  traced / evaluated by
                    ┌────────▼────────┐
                    │    LangSmith    │  观测、评估、部署（与具体框架解耦）
                    └─────────────────┘

Integrations：独立 packages（openai、anthropic…）接入 Core 抽象
```
